# 文本检查与图片审核调研

核对日期：2026-09-14。

## 当前文本检查

页面在保存编辑、导入更新包和导出更新包时，逐个检查文本字段。词项来自 https://file.peteralbus.com/assets/files/text-review-rules.json，维护文件为 `publishing/text-review-rules.json`，检查入口在 `src/package-text-review.mjs`。规则由产品选定，不是平台提供的完整合规词库。

每次操作通过不携带凭据的 GET 请求获取词库，使用 `cache: no-store` 避免浏览器复用长期缓存；仅下载词库，点位文字和图片在本机处理。响应须为有效 JSON，包含正整数 `version` 和 `rules` 数组；各分类包含 `category`（`sexual` 或 `politics`）、`label` 和字符串数组 `terms`。词项不能是空白或仅有标点。`version` 表示词库修订，不影响点位包格式。

网络、HTTP、JSON、字段校验失败或请求超过 5 秒时，本次操作继续，仅执行页面内置的链接检测。操作完成后以 message 提示“词库加载失败，本次未进行敏感词检查”。下一次操作重新获取词库，恢复后使用新的词项。词库下载和校验的错误单独处理；命中规则造成的审核失败仍会中止操作。

- 检查内容：链接、明确色情词项，以及词库列出的中国相关政治人物、组织、事件名称。普通地名不单独拦截。
- 检查范围：更新包作者、点位名称、区域、操作说明、上传者姓名、各类图片说明和扩展文本。导入、导出时新增记录、修改前后快照、删除前快照均检查；v6 的引用图片说明也检查。
- 标识符、坐标、图片逻辑路径、校验值、时间戳、身份 ID 等结构字段由原有格式校验负责。教学视频字段仍只接受 BV 号或空值，不接受网址。
- 检查前统一大小写、全角字符和不可见字符。中文词项同时检查插入空白或标点的写法；英文词项按边界匹配。链接检测包括常见协议、裸域名、IPv4、Markdown 和 HTML 链接形式。
- 导入：格式及文件完整性验证后检查整个包，再解析图片引用和应用数据。存在命中时拒绝整个包，不丢弃文字后继续导入，也不应用其中的其他记录。
- 导出：编辑页、查看页和历史页共用下载函数；生成 ZIP 前重新检查当前包，命中时不创建下载文件。提示指出记录序号、字段和命中类别，最多展示前三处及剩余数量，不回显命中原文。
- 保存：写入本地存储前检查本地编辑包的作者、新增及修改后点位、图片说明等当前文本。命中时保留草稿、当前选择与上次保存的数据。修改前和删除前快照不参与保存检查，因此可以修正或删除旧资料中的问题文本；再次交换时，包内快照仍须通过检查。
- 启动时正常读取已有资料。v4/v5/v6 格式及本地存储版本不变。

本地检查只判断有限规则是否命中，不能识别所有语义、谐音、暗示和变形写法，也可能误判同名或形似域名的文本。前端逻辑和词库可被使用者修改或绕过，因此不能单独证明平台合规。当前没有对图片像素、图中文字或二维码执行审核。

## 图片审核的低成本选择

| 方案 | 覆盖内容 | 费用与条件 | 对当前项目的适用性 |
| --- | --- | --- | --- |
| NSFWJS 浏览器模型 | 色情相关图像分类 | 开源 MIT；无按次 API 费，需下载模型并占用用户设备算力 | 可保持静态部署，适合色情初筛；不能据此判断中国相关政治内容、图片文字或链接 |
| Tesseract.js + ZXing + 当前词库 | 图中文字及可解码二维码内的链接、词项 | 无按次 API 费；需 OCR 模型、计算与规则维护 | 可补足图片文字/链接检查；不识别政治人物肖像、旗帜等视觉语义，识别失败不能视为已通过 |
| 阿里云图片审核增强版 | 通用基线包含色情和涉政等风险；广告引流等需核对相应服务配置 | `image_standard` 按量 15 元/万次，每调用一个服务独立计费 | 少量真实审核请求的调用费用较低，需要服务端保管凭据 |
| 腾讯云图片内容安全 | 标准图片风险检测，含色情、引流二维码、OCR 等，需按实际开通策略验证政治检测范围 | 官方快速入门列出后付费 25 元/万张；首次开通试用 3,000 张，15 天有效 | 有试用额度，适合先用真实游戏截图评估，需服务端调用 |

NSFWJS 官方列出 Drawing、Hentai、Neutral、Porn、Sexy 五类，其结果是分类概率，不是完整安全判定。模型应自行托管，部署前需实测 Toy 环境中的模型下载、Worker、推理性能和手机内存占用。[NSFWJS 官方仓库](https://github.com/infinitered/nsfwjs)

Tesseract.js 可在浏览器内运行 OCR，官方明确说明它不会修改底层识别模型来提高准确率。ZXing 浏览器库可从图片读取二维码；OCR/二维码解析的结果可以交给同一文本规则检查。对小字、描边、压缩和遮挡截图的效果需要实际验证。[Tesseract.js 官方说明](https://github.com/naptha/tesseract.js/blob/master/docs/faq.md)、[ZXing 浏览器接口](https://github.com/zxing-js/browser/blob/master/README.md)

阿里云通用基线检测支持配置色情、涉政等范围，广告引流属于可另行选择的内容治理场景。“不允许任何链接”比供应商的“风险广告引流”更严格，需验证是否能取得 OCR/二维码结果并追加链接规则。[检测范围配置](https://help.aliyun.com/zh/document_detail/467827.html)、[OCR 等辅助结果接口](https://help.aliyun.com/zh/document_detail/2528737.html)

阿里云的 15 元/万次是单服务按量价格；同一张图调用多个服务分别计费。通用图片审核使用资源包时的抵扣系数为 2，开启附加大模型能力还会增加计费项，不能直接把资源包标注次数当作可审核图片张数。[官方计费说明](https://help.aliyun.com/zh/document_detail/467826.html)

腾讯云当前快速入门说明：首次开通 3,000 张试用包有效期 15 天，后续按量后付费为 25 元/万张，图片文件限制 5 MB。本站允许的原始上传大小较大，接入前需处理服务支持的大小和格式，并保证审核对象就是最终分享的图片。[官方开通与价格说明](https://cloud.tencent.com/document/product/1125/37109)、[图片内容安全能力](https://cloud.tencent.com/document/product/1124/137268)

## 费用量级和建议

按每张图片调用一次服务、不计免费额度计算：

| 实际审核调用量 | 阿里云单服务按量 | 腾讯云按量后付费 |
| --- | ---: | ---: |
| 1,000 次 | 1.5 元 | 2.5 元 |
| 10,000 次 | 15 元 | 25 元 |
| 100,000 次 | 150 元 | 250 元 |

以上由官方单价换算，不包括函数、网关、流量、存储或附加审核服务费用。导入和导出都重新调用时，费用按实际调用次数增加。

如果图片要求同时覆盖色情、中国相关政治视觉内容和图片链接，建议优先用国内云审核做效果评估。仅把 NSFWJS 接入页面不能完成这三个目标。需要坚持完全静态部署时，本地模型加 OCR/二维码只能作为辅助检查，不能承诺达到同样的审核范围。

选型时先用真实游戏截图做小规模测试，覆盖武器、技能特效、英雄头像和带教学文字的图片，分别统计漏检与误判。审核策略应对应本次要求的三类内容，不能将服务返回的所有风险标签都直接作为拦截条件。还需在 Toy 预览环境确认外部请求、CORS、Worker 和模型加载限制。

减少重复调用可复用项目现有的 SHA-256：由服务端根据实际图片字节计算摘要，按“摘要 + 审核策略版本”保存结果；命中同一审核策略的已有结果时可复用，策略变化时重新审核。v6 引用图片也应按实际解析得到的图片摘要查询结果，不能仅因包内没有携带文件就跳过。

云端接入至少需要一个受保护的审核接口，云厂商密钥仅放在服务端，并限制接口滥用和调用预算。阿里云官方 SDK 文档明确提醒不要把 AccessKey 写进工程代码。[凭据使用说明](https://help.aliyun.com/zh/document_detail/467828.html)

这部分是图片审核的调研建议，当前实现提供保存编辑和更新包交换的文本检查，未上传用户图片或开通收费服务。
